# 🌿 Зелёный Дом — магазин комнатных растений

Многостраничный сайт интернет-магазина комнатных растений. Чистый
HTML/CSS/JavaScript, без сборки и зависимостей — достаточно открыть
`index.html` в браузере.

## Страницы

| Файл | Описание |
|------|----------|
| `index.html` | Главная: hero, преимущества, категории, хиты продаж, блог |
| `catalog.html` | Каталог с фильтром по категориям, фильтром «безопасно для питомцев» и сортировкой |
| `product.html?id=…` | Карточка товара: фото, характеристики, выбор количества, похожие растения |
| `cart.html` | Корзина: изменение количества, удаление, расчёт доставки, промокод |
| `checkout.html` | Оформление заказа: контакты, доставка, оплата, валидация формы |
| `blog.html` | Блог со статьями об уходе |
| `article.html?id=…` | Страница статьи |
| `about.html` | О магазине: история, цифры, ценности, команда |
| `contacts.html` | Контакты, карта и форма обратной связи |

## Возможности

- **Полностью кликабельный**: навигация, карточки, корзина, фильтры, формы.
- **Корзина** хранится в `localStorage` и работает между всеми страницами.
- **Адаптивная вёрстка** (десктоп / планшет / мобильный с бургер-меню).
- **Валидация форм** оформления заказа и обратной связи.
- **Бело-зелёная палитра**, аккуратная типографика (Inter), мягкие тени.

## Структура

```
.
├── index.html, catalog.html, product.html, cart.html,
│   checkout.html, blog.html, article.html, about.html, contacts.html
└── assets/
    ├── css/style.css      — дизайн-система и все стили
    └── js/
        ├── data.js        — каталог растений и статьи блога
        ├── app.js         — шапка/подвал, корзина, помощники
        └── (логика страниц — внутри соответствующих .html)
```

## Изображения

Фотографии растений сгенерированы нейросетью (Higgsfield Soul) и
подключаются по ссылкам с CDN. Если изображение недоступно, на его месте
аккуратно показывается зелёный плейсхолдер 🪴 (см. `.img-fallback` в CSS).

## Как запустить

Просто откройте `index.html` в браузере. Для локального сервера:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```
